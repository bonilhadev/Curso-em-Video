# Lógica de Programação e Algoritmos

Repositório de exercícios e anotações desenvolvidos durante meus estudos de **Lógica de Programação e Algoritmos** no Curso em Vídeo.

O objetivo deste curso é desenvolver minha base de programação, trabalhando conceitos fundamentais que serão utilizados posteriormente em outras linguagens e projetos.
