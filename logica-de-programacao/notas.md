# Anotações — Lógica de Programação

## Tipos primitivos

### Inteiro

Exemplos:

- 1
- 3
- -5
- 198
- 0

### Real

Exemplos:

- 0.5
- 5.0
- 9.8
- -77.3

### Caractere

Exemplos:

- "Italo"
- "Algoritmo"
- "123"

Representa uma sequência de caracteres.

### Lógico

Possui dois valores possíveis:

- verdadeiro
- falso
